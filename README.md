# KOTCOOP · Jokerweek 2027

Website (installable web-app) for the Jokerweek of the master's students Engineering Architecture at UGent, 22–26 March 2027: a student housing cooperative in Ghent.

Live at GitHub Pages once Pages is turned on (Settings → Pages → Branch: main).

## Editing content

Everything is in `index.html`. The parts you are most likely to change are near the bottom, marked `(edit here)`:

- `DAYS`: the schedule
- `MENU`: food
- `PLACES`: locations (name, description, address, latitude, longitude)
- `WIKI`: wiki pages
